# 同窗

香港小學課堂用的協作壁報。學生不用註冊帳戶：老師建立課室，把**一個課室連結**交給全班。連結裡面可以新建多塊壁報，學生打開就看到所有人的作品。

介面是繁體中文（香港）。

## 本地運行

需要 Node.js 22.5 或以上。

```bash
npm install
npm run dev
```

打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

資料存在 `data/classroom.db`，上傳的圖片在 `data/uploads/`。這兩個位置已加入 `.gitignore`。

正式環境：

```bash
npm run build
npm start
```

`npm start` 會在同一個埠提供網頁、API 和 WebSocket。

## 教師怎樣使用

1. 在首頁揀「我係老師」，再建立新課室。輸入課室名稱（例如「三年甲班」）和老師密碼。密碼至少 4 個字元，系統不會提供找回功能，請自己記住，唔好同學生講。
2. 之後在同一部電腦會保持登入。換電腦時揀「我係老師」，再進入已有課室，用同一個名稱和密碼。
3. 進入課室頁（網址是 `/c/課室編號`）。按「＋ 新建壁報」。
   - **壁報板**：文字、圖片（上傳或網址）、YouTube。可在「自由擺放」和「整齊排列」之間切換。
   - **互動畫布**：無限畫布。可以揀、畫筆、文字、便利貼、圖形、箭咀同相片。拖動空白處移動，滾輪縮放。全班同一塊。
   - **作品集**：多張白色卡片。老師預先開好卡片（例如「第1組」「範例」），學生用同一條連結揀卡片，小組可以一齊寫字、上載相片、畫筆註解同基本圖形。底列有縮圖同「＋ 卡片」。預設學生唔可以自己加卡片；老師可以喺工具入面開放。暫停編輯之後，學生只可以睇。
   - 每塊板有兩個碼，同「分享連結」分開。綠色「掃碼入板」打開 `/b/…`。紅色「掃碼交作品」去交相頁（`/u/…`），檔案放進老師先睇到的「學生上載」資料夾，24 小時後自動刪除；老師「放上板」的副本會留低。有學生密碼仍然要輸入。老師可以暫停上載。
   - 相片會先在學生的裝置轉成 JPG 再上載，方便 iPhone 的 HEIC 同大圖。圖片存在 `DATA_DIR/uploads`（正式環境是 `/app/data/uploads`）。
4. 組別可以留空，或填「第1組」。這是標籤，不是學生名冊。全班用同一條課室連結，裡面可以有多塊壁報。
5. 按「複製課室連結」交給學生。學生打開這一個連結，就看到所有壁報和裡面其他人的作品。
6. 在壁報上可以鎖定（學生只能看）、刪除任何貼文，或在「⋯」裡設定、刪除整塊壁報。

學生用老師分享的課室連結打開 `/c/課室編號`（首頁「我係學生」也可以貼上連結）。可以看到每塊壁報上其他人的作品，再進入某一塊板貼文。第一次會問「你叫咩名？」。暱稱存在這個分頁的 sessionStorage，關掉分頁後要再填，方便學校共用電腦。

用兩個瀏覽器視窗打開同一條連結，就可以看到貼文即時同步。

## 環境變數

全部都可以不填，本機直接 `npm run dev` 就能用。見 `.env.example`。

| 變數 | 作用 |
| --- | --- |
| `PORT` | 預設 `43123` |
| `DATA_DIR` | 資料庫和圖片目錄，預設 `./data` |
| `PUBLIC_URL` | 學生 QR 碼用的公開網址。在正式網址打開時會用當前網址。只在本機開啟、又想碼指向正式網站時先要填，例如 `https://tongchung-production.up.railway.app`。Railway 未填時會用 `RAILWAY_PUBLIC_DOMAIN`。 |
| `AUTH_SECRET` | 簽發登入憑證的密鑰。未設定時會寫入 `DATA_DIR/auth-secret.txt`。部署時請自行設定，並保持不變，否則老師和學生要重新進入。 |

即時同步用這個程式內建的 WebSocket（路徑 `/ws`），**不用** Firebase、Supabase 或其他 API 金鑰。

## 部署

這是單一 Node 程式，適合長駐的一台機器。請掛上持久磁碟到 `DATA_DIR`（SQLite 和圖片），不要部署到無狀態的 serverless（例如 Vercel），因為 WebSocket 和 SQLite 需要同一個持續運行的程序。多台機器同時寫入同一份 SQLite 也不適合；請以單一個實例運行。

- **Docker**：`docker build -t tongchung .` 然後 `docker run -p 43123:43123 -v tongchung-data:/app/data -e AUTH_SECRET=一段隨機字串 tongchung`
- **Fly.io / Railway / Render**：用上面的 Dockerfile 或 `npm run build && npm start`，設定 `PORT`、`AUTH_SECRET`，並把磁碟掛到 `/app/data` 或你的 `DATA_DIR`。

## 限制

- 錄音和 Spotify 只顯示「即將推出」，尚未實作。
- 圖片接受 JPG、PNG、GIF、WebP，最大 12MB。iPhone 的 HEIC 會在上載前轉成 JPG。
- 學生密碼不是高強度帳戶系統，只用來避免其他班打開連結。
- 已進入的分頁在密碼更改後仍可繼續使用，直到關掉分頁或憑證過期（約 7 日）。
